Go live in Firefox?

    

      
gnash opens a second Firefox window running a copy of this profile: your prefs, user.js, toolbar layout, extensions and chrome/ files. Every edit shows up there as you type. Your everyday Firefox keeps running and isn't touched.

      
    
        
  • Nothing changes in your real profile until you save.
    • 
        
  • The copy shows a robot icon and a striped address bar; that's Firefox's remote-control mode.
    • 
        
  • While live, other programs on this computer could also control that copy.
    • 
        
  • Turning Live off closes the copy.
